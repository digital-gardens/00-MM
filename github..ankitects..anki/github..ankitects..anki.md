The desktop app does not automatically install updates, but it displays a notification on startup when a new version is released.

Anki comes with exactly zero preinstalled add-ons.

Find out the number code for the add-on you don't want to update via "Tools > Add-ons > View add-on page", and then rename that add-on's folder in your Anki directory (%APPDATA%\Anki2\addons21), for example "1666520655" to "MIA_Retirement_1666520655".
